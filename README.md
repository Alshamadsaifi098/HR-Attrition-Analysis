# HR-Attrition-Analysis
HR Attrition Analysis project including data cleaning, exploratory data analysis (EDA), KPI development, and interactive dashboard creation in Power BI.
Step 1: Data Collection

Employee attrition increases hiring cost, reduces productivity, and affects overall company performance.

This project answers:

Which age group has the highest attrition?
Does salary impact employee turnover?
Which job roles are most affected?
How does experience influence attrition?


Data Cleaning & Preparation

Before visualization, the following steps were performed:

Checked and handled missing/null values
Removed duplicate records
Standardized categorical columns
Created Salary Slabs 
Validated employee count & attrition numbers
Prepared data model in Power BI

Key Insights

Highest attrition in 26–35 age group
Lower salary employees more likely to leave
Sales department has high turnover
Early-career employees (0–3 years) leave more frequently

 Business Recommendations

Improve compensation strategy
Focus on retention in Sales department
Provide growth opportunities for early-stage employees
Strengthen employee engagement programs
